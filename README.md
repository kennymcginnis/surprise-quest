# Surprise Quest Meeting Notes

Meeting minutes and transcripts are published as a searchable Docsify site:

**[Open the meeting notes](https://kennymcginnis.github.io/surprise-quest/)**

The site source is in [`docs/`](docs/). To preview it locally, run:

```sh
npx docsify-cli serve docs
```

Changes pushed to `main` are published to GitHub Pages by the workflow in
[`.github/workflows/pages.yml`](.github/workflows/pages.yml).
